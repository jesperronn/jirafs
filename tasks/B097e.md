# B097e: Render linked issues with direction, fix versions, sub-tasks and parent.

## Dependencies

B097c

## Owned paths

`internal/export/**`, `internal/schema/**`, `internal/codec/**`, `internal/plan/**`

## Acceptance

**Linked issues.** Render them as `linked_issues: [{key, relation, summary, status}]`, where `relation` is the directional text (`blocks` or `is blocked by`) taken from the link type's `outward` and `inward` names. Stop de-duplicating by key alone: de-duplicate by key plus relation. Plan comparison of linked issues still uses only key and relation.

**Fix versions.** Fill `fix_versions` from `fields.fixVersions[].name`.

**Sub-tasks.** Add a read-only `subtasks: [{key, summary, status}]` field. Sub-tasks get `parent: KEY`. Mirror does not fetch sub-tasks recursively.

Use the B097c fixture with each kind of data and add round-trip tests.

- No placeholder code, no TODO comments, no partial implementations.
- Add tests in the same task.
- Final gates: `bin/test` and `bin/lint` must both pass.
- Commit with conventional commit wording after gates pass.
- Move this file to `tasks/done/` as part of the same commit.
