# B097d: Add the 20 most recent comments as a read-only section.

## Dependencies

B097c

## Owned paths

`internal/jira/**`, `internal/export/**`, `internal/schema/**`, `internal/plan/**`

## Acceptance

Add `JiraClient.FetchComments(ctx, key, limit)`. It calls `/rest/api/2/issue/KEY/comment?orderBy=-created&maxResults=20`.

Render the comments as a `## Comments` section, newest first. Each comment has an `### <author> — <created RFC3339>` header followed by its body. If the total is more than 20, add the line `_(showing 20 of N comments)_`.

The section is machine-owned: the parser keeps it, and plan/push never produce a diff from edits to it. Export and mirror both include comments. A failed comments fetch is a warning to stderr, not an error.

Tests cover:
- ordering
- the 20-comment cap and its note
- the plan ignoring edited comments
- a failed comments fetch
