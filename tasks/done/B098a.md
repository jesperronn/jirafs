# B098a: AI pipe for new issues: `new --prompt` and `new --from`.

## Dependencies

none

## Owned paths

`internal/cli/**`, `README.md`

## Acceptance

`jirafs new <type> --prompt [--idea TEXT]` prints the template plus concise AI instructions (fill sections, keep frontmatter keys, output only the document). `buildPrompt(template, idea)` is the seam where a built-in LLM call can later plug in.

`jirafs new --from <file|->` reads a filled document, validates it with the codec (type and summary required), applies `--project`/`--assignee`, writes the draft and prints `jirafs: created <path>`. Validation errors name the offending field and print a copy-pasteable retry command.

README documents `jirafs new story --prompt --idea "..." | llm | jirafs new --from -`.
